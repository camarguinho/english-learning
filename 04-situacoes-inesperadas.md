## Padrões úteis para imprevistos

| Inglês | Português |
|---|---|
| It's 7 AM. / It's noon. / It's midnight. | São 7h. / É meio-dia. / É meia-noite. (sempre com "it's") |
| I'm not sure either. (negativa) / I like it too. (afirmativa) | Eu também não tenho certeza. / Eu também gosto. |
| Let me check my phone. | Deixa eu checar meu celular. (sem preposição "in") |
| Hold on, please. / Just a second. | Espera um pouco, por favor. (mais educado que "wait") |
| Sorry, I'm in a hurry! / I'm running late. | Desculpa, estou com pressa! / Estou atrasado. |
| I'm not from here, I'm from Brazil. | Não sou daqui, sou do Brasil. |
| I have no idea, sorry. | Não faço ideia, desculpa. |
| And you? / What about you? | E você? (devolver a pergunta em small talk) |

## Está perto / está longe

| Inglês | Português |
|---|---|
| It's close by. / It's just around the corner. | É bem pertinho. / É logo ali na esquina. |
| It's within walking distance. | Dá pra ir a pé. |
| It's a bit far from here. / It's far away. | É um pouco longe daqui. / É bem longe. |
| It's about 10 minutes from here. | Fica a uns 10 minutos daqui. |

## Está demorando / está rápido

| Inglês | Português |
|---|---|
| This is taking forever. | Isso está demorando uma eternidade. |
| It's taking longer than expected. | Está demorando mais do que o esperado. |
| That was fast! / This should be quick. | Isso foi rápido! / Isso deve ser rápido. |
| It won't take long. / Sorry for the wait. | Não vai demorar. / Desculpa pela espera. |

## É seguro / é arriscado

| Inglês | Português |
|---|---|
| This area is safe. | Essa área é segura. |
| It's a bit risky to go there alone. | É um pouco arriscado ir lá sozinho. |
| I wouldn't recommend it, it can be dangerous. | Eu não recomendaria, pode ser perigoso. |
| Keep an eye on your belongings there. | Fique de olho nos seus pertences lá. |

## Recomendo / não recomendo

| Inglês | Português |
|---|---|
| I'd definitely recommend trying it. | Eu com certeza recomendaria experimentar. |
| I don't recommend going there. | Eu não recomendo ir lá. |
| It's not really worth it. / If I were you, I'd avoid it. | Não vale muito a pena. / No seu lugar, eu evitaria. |
| It's highly recommended by locals. | É muito recomendado pelos moradores locais. |

## Está cheio / vazio / caro / barato

| Inglês | Português |
|---|---|
| This place is packed. / It's empty at this hour. | Esse lugar está lotado. / Está vazio nesse horário. |
| It gets busy around lunchtime. | Fica cheio perto do horário de almoço. |
| This is quite expensive. / It's pretty cheap around here. | Isso é bem caro. / É bem baratinho por aqui. |
| That's a good deal. / It's overpriced. | Isso é um bom negócio. / Está com preço abusivo. |
