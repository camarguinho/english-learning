## G. Pronúncia e Entonação

> Para o dicionário completo de pronúncia palavra-por-palavra (com IPA), veja o [Dicionário de Pronúncia](dicionario-pronuncia.md).

### G1. Word stress — a sílaba tônica muda o som da palavra

Em inglês, colocar a força na sílaba errada pode deixar a palavra irreconhecível, mesmo com todas as letras certas. Muitas palavras técnicas mudam de padrão ao virar outra classe gramatical.

| Palavra (CAIXA ALTA = sílaba forte) | Tradução |
|---|---|
| comPUter (substantivo) | computador |
| DEveloper (substantivo) | desenvolvedor |
| arCHItecture (substantivo) | arquitetura |
| PHOto → phoTOgraphy → photoGRAPHic | foto → fotografia → fotográfico (a sílaba tônica se move) |
| reCORD (verbo) vs. RECord (substantivo) | gravar (verbo) vs. gravação/disco (substantivo) |

### G2. Sons que não existem em português (pares mínimos)

| Par de palavras | Significado |
|---|---|
| think / sink | pensar / afundar (o "th" não existe em pt) |
| ship / sheep | navio / ovelha (vogal curta i vs. longa i) |
| live / leave | viver / partir (mesma lógica de vogal) |
| very / berry | muito / fruta silvestre (o "v" em inglês não vira "b") |
| work / walk | trabalhar / caminhar (vogais bem diferentes) |

### G3. Linking — como as palavras se conectam na fala natural

| Frase escrita → como soa falada | Tradução |
|---|---|
| turn it off → soa como "tur-ni-toff" | desligar isso |
| an apple → soa como "a-napple" | uma maçã |
| check it out → soa como "che-ki-tout" | confira isso |
| not at all → soa como "no-ta-tall" | de jeito nenhum |

**Dica:** entender linking ajuda muito na ESCUTA (por isso frases nativas parecem "rápidas demais"); praticar produzindo aos poucos deixa sua fala mais natural também.

### G4. Entonação: perguntas vs. afirmações

| Frase (padrão de entonação) | Tradução |
|---|---|
| Are you coming? (tom sobe no final) | Você vem? (pergunta yes/no) |
| Where are you going? (tom desce no final) | Aonde você vai? (Wh-question) |
| I'm coming. (tom desce, afirmação) | Eu vou. |
| You're coming, right? (sobe levemente — tag question) | Você vem, né? |

## H. Verbos Modais

### H1. Can / Could — habilidade e pedidos educados

| Inglês | Português |
|---|---|
| I can fix this today. | Eu consigo corrigir isso hoje. |
| Could you help me with this? | Você poderia me ajudar com isso? |
| Can I ask you something? | Posso te perguntar uma coisa? |
| I could speak a little English as a kid. | Eu conseguia falar um pouco de inglês quando criança. |

### H2. Should / Must — sugestão vs. obrigação forte

| Inglês | Português |
|---|---|
| You should review this code before merging. | Você deveria revisar esse código antes do merge. |
| We must fix this before the release. | Precisamos corrigir isso antes do lançamento. (obrigatório) |
| This should work, but let's test it. | Isso deve funcionar, mas vamos testar. |
| You must have a valid ID to check in. | Você precisa ter um documento válido para o check-in. |

### H3. Might / May — possibilidade

| Inglês | Português |
|---|---|
| This might cause a memory leak. | Isso pode causar um memory leak. (possibilidade) |
| It may take longer than expected. | Pode ser que demore mais do que o esperado. |
| We might need to refactor this later. | Pode ser que precisemos refatorar isso depois. |
| May I come in? | Posso entrar? (mais formal que "can") |

### H4. Modais em contexto técnico (reuniões)

| Inglês | Português |
|---|---|
| This could cause a bug in production. | Isso pode causar um bug em produção. |
| You should consider using a different pattern. | Você deveria considerar usar outro padrão. |
| We must fix this before deploying. | Precisamos corrigir isso antes de lançar. |
| This might not scale well. | Isso pode não escalar bem. |

## I. Conectores e Fillers de Conversação

### I1. Conectores de contraste

| Inglês | Português |
|---|---|
| I like the idea; however, it has some risks. | Gosto da ideia; porém, tem alguns riscos. |
| Although it's more complex, it's more flexible. | Embora seja mais complexo, é mais flexível. |
| It works, but it's not the best solution. | Funciona, mas não é a melhor solução. |
| Despite the delay, we finished on time. | Apesar do atraso, terminamos no prazo. |

### I2. Conectores de adição e sequência

| Inglês | Português |
|---|---|
| We also need to test the edge cases. | Também precisamos testar os casos extremos. |
| In addition, this reduces the technical debt. | Além disso, isso reduz a dívida técnica. |
| First, we identify the bug; then, we fix it. | Primeiro identificamos o bug; depois, corrigimos. |
| Next, let's look at the database schema. | A seguir, vamos olhar o schema do banco. |

### I3. Conectores de causa e consequência

| Inglês | Português |
|---|---|
| The service was down, so we rolled back. | O serviço caiu, então revertemos. |
| Because the load increased, we scaled up. | Como a carga aumentou, escalamos. |
| As a result, the response time improved. | Como resultado, o tempo de resposta melhorou. |
| Therefore, we recommend this approach. | Portanto, recomendamos essa abordagem. |

### I4. Fillers — ganhar tempo pra pensar sem travar

| Inglês | Português |
|---|---|
| Well, let me think about that. | Bem, deixa eu pensar sobre isso. |
| Actually, I think there's a better way. | Na verdade, acho que tem um jeito melhor. |
| You know, this reminds me of another bug. | Sabe, isso me lembra outro bug. |
| I mean, it depends on the context. | Quer dizer, depende do contexto. |
| So, basically, the idea is to separate the logic. | Então, basicamente, a ideia é separar a lógica. |

## J. Perguntas (Wh- e Tag Questions)

### J1. Wh-questions — estrutura básica

| Inglês | Português |
|---|---|
| What did you find in the logs? | O que você encontrou nos logs? |
| Why did the service go down? | Por que o serviço caiu? |
| How does this pattern work? | Como esse padrão funciona? |
| Where is the meeting room? | Onde fica a sala de reunião? |
| Who is responsible for this module? | Quem é responsável por esse módulo? |

### J2. Perguntas Yes/No

| Inglês | Português |
|---|---|
| Do you have the report ready? | Você tem o relatório pronto? |
| Does this affect the other services? | Isso afeta os outros serviços? |
| Did you test this before deploying? | Você testou isso antes de lançar? |
| Is the server still down? | O servidor ainda está fora do ar? |

### J3. Tag questions — confirmando algo no final da frase

Regra: afirmativa + tag negativa; negativa + tag afirmativa.

| Inglês | Português |
|---|---|
| This is a good approach, isn't it? | Essa é uma boa abordagem, né? |
| You tested this, didn't you? | Você testou isso, né? |
| It's not that complex, is it? | Não é tão complexo, né? |
| We can fix this today, can't we? | A gente consegue corrigir isso hoje, né? |

## K. Condicionais (If Clauses)

### K1. Zero conditional — fatos gerais e verdades

If + presente, presente. Usado pra fatos sempre verdadeiros (regras, ciência, comportamento padrão do sistema).

| Inglês | Português |
|---|---|
| If you heat water to 100°C, it boils. | Se você aquece água a 100°C, ela ferve. |
| If the cache is empty, the system queries the database. | Se o cache está vazio, o sistema consulta o banco. |
| If a test fails, the pipeline stops. | Se um teste falha, o pipeline para. |

### K2. First conditional — situações reais e futuras

If + presente, will + verbo. Usado pra consequências reais e prováveis no futuro.

| Inglês | Português |
|---|---|
| If this fails, we'll roll back. | Se isso falhar, vamos reverter. |
| If the load increases, we'll need to scale. | Se a carga aumentar, vamos precisar escalar. |
| If you deploy now, it might break production. | Se você lançar agora, pode quebrar a produção. |
| If I have time, I'll review your PR today. | Se eu tiver tempo, reviso seu PR hoje. |

### K3. Second conditional — hipóteses e conselhos

If + passado, would + verbo. Usado pra situações hipotéticas, improváveis ou conselhos.

| Inglês | Português |
|---|---|
| If I were you, I'd refactor this first. | No seu lugar, eu refatoraria isso primeiro. |
| If we had more time, we would rewrite this module. | Se tivéssemos mais tempo, reescreveríamos esse módulo. |
| If I knew the answer, I would tell you. | Se eu soubesse a resposta, eu te diria. |
| What would you do if this happened in production? | O que você faria se isso acontecesse em produção? |

## L. Falsos Cognatos Ampliados

### L1. Palavras parecidas, significados diferentes

| Palavra em inglês = sentido real | Equivalente em português |
|---|---|
| actually = na verdade (não "atualmente") | atualmente = currently / nowadays |
| pretend = fingir (não "pretender") | pretender = to intend / to plan |
| push = empurrar (não "puxar") | puxar = to pull |
| parents = pais/mãe (não "parentes") | parentes = relatives |
| realize = perceber/se dar conta (não "realizar") | realizar = to carry out / to accomplish |
| fabric = tecido (não "fábrica") | fábrica = factory |
| college = faculdade (não "colégio") | colégio = high school |
| library = biblioteca (não "livraria") | livraria = bookstore |
| exit = saída (não "êxito") | êxito = success |
| intend = pretender/planejar (não "entender") | entender = to understand |
| **assume = presumir/supor, sem confirmar** (não "assumir responsabilidade") 🆕 *11/ago/2026* | assumir (responsabilidade) = to take on / **to take over** |
| **benefit(s) = vantagem, algo bom que você ganha** (não "benefice") 🆕 *14/ago/2026* | benefício (vantagem) = benefit(s) |
| eventually = finalmente, no fim das contas (não "eventualmente") 🆕 *14/ago/2026* | eventualmente (às vezes, por acaso) = occasionally / possibly |
| sensible = sensato, razoável (não "sensível") 🆕 *14/ago/2026* | sensível (emocional, físico) = sensitive |
| notice = perceber / aviso (não "notícia") 🆕 *14/ago/2026* | notícia = news |
| attend = comparecer, participar de algo (não "atender") 🆕 *14/ago/2026* | atender (responder, servir) = to answer / to serve |

> **Exemplo real seu:** ❌ "I assumed my colleague's tasks." → ✅ **"I took over my colleague's tasks."** ("Assume" em inglês é presumir algo sem confirmar — "I assume it's fine" = eu imagino que está tudo bem — não tem nada a ver com assumir responsabilidade.)
>
> **Exemplo real seu:** ❌ "I showed them the benefices." → ✅ **"I showed them the benefits."** ("Benefice" existe em inglês, mas é raro e tem outro sentido — um cargo eclesiástico com renda, ligado à igreja. Nada a ver com "vantagem/benefício" no sentido comum, que é sempre "benefit(s)".)
>
> **Dica — "eventually" é uma pegadinha clássica em post-mortem:** "We eventually found the root cause" = "No fim das contas, encontramos a causa raiz" (depois de um processo). Não é "eventualmente" no sentido de "às vezes" — pra isso, use "occasionally" ou "sometimes".
>
> **Bônus — pronome:** cuidado com "yours" quando a tarefa não é sua. "I took over yours tasks" aponta a tarefa pra mim; se é do colega, o certo é **"I took over their tasks."** O inglês marca de quem é a coisa de um jeito mais explícito que o "seu/sua" do português, que serve pra qualquer pessoa.
