# Guia Definitivo de Inglês — Camargo

Plano de fluência consolidado, migrado de PDF para uma estrutura de arquivos markdown evolutiva. Este é o material de referência único — do básico ao avançado — construído sessão após sessão.

**Filosofia:** este repositório é um documento vivo. Cada erro real, cada correção que engata numa conversa de verdade, ganha um lugar fixo aqui — não fica perdido em uma conversa isolada. Quando um ponto novo aparece numa sessão, ele entra no capítulo certo, marcado com 🆕 e a data.

## Como este repositório cresce

- Um erro novo, corrigido numa conversa real → entra no **capítulo certo**, não em arquivo novo.
- A marca `🆕 dd/mm/aaaa` identifica o que veio de uma sessão real (não de teoria pura) — assim dá pra rastrear a evolução.
- Uma palavra nova que travou → vai para o [Dicionário de Pronúncia](dicionario-pronuncia.md).
- Um tema totalmente novo (que não cabe em nenhum capítulo existente) → aí sim, arquivo novo, listado aqui no sumário.

## Como usar

Ver [Parte 0](00-plano-de-fluencia.md) para o plano de estudo completo. Resumo rápido: 1 tópico por dia, regra + exemplo em voz alta + frase própria sua, sempre combinando gramática com prática de produção real — narrar o próprio dia é o exercício que mais destrava.
